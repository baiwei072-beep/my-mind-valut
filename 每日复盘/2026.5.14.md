## 决策训练（今天有卡住就写一个）

> 目的：把焦虑里的反应，变成事实、判断、选择和同步。不要一上来就进入技术实现和执行细节。

- 卡住的决策：写清“我到底要决定什么”，避免把一团焦虑当成问题。
- 目标：写这件事真正要达成的结果，避免用“处理好”糊弄自己。
- 当前层级：判断我现在站在哪一层看问题：执行 / 项目 / 产品 / 业务 / 组织 / 战略。
- 更高一层：如果往上站一层，这件事服务什么目标：增长 / 收入 / 留存 / 效率 / 风险控制 / 其他。
- 事实：只写已经确认、可以验证的东西，避免把猜测当事实。
- 推测：写还没证据但我脑子里正在相信的判断，避免被隐形假设带着走。
- 恐惧 / 在保护什么：写我最怕失去什么，避免把情绪误判成优先级。
- 紧急度：判断今天必须处理 / 明天可处理 / 可以排期，避免把压力当紧急。
- 选项：列出至少两个选项，避免只盯着第一反应。
- 收益和代价：每个选项分别写收益、代价、最大风险，避免只看好处或只看坏处。
- 选择：基于目前事实，我先选择什么，避免无限犹豫。
- 最小下一步：写下一步谁在什么时候做什么，避免停在“想明白了”。
- 对外同步：用四句话说清：确认了什么 / 未确认什么 / 风险是什么 / 下一步是什么。
